# 🛠️ Features

The **Admin Dashboard** is a comprehensive solution designed for managing users, events, and academic records with a modern, responsive interface.

## 🖥️ Dashboard
- **Overview Analytics**: Real-time stats on users, events, and performance.
- **Data Visualization**:
  - **Radar Charts**: Comparative analysis of scores/metrics.
  - **Bar Charts**: Event frequency and enrollment tracking.
- **Recent Activity**: Quick view of the latest approved and pending events.

## 👥 User Management
- **Role-Based Access Control**:
  - **Admins**: Full system access.
  - **Schools**: Manage school-specific data.
  - **Animators**: Specialized role for event animation/coordination.
- **Bulk Upload**: Import multiple users via CSV with validation.
- **Advanced Filtering**: Filter users by role, email, or school name.
- **User Profiles**: Detailed view of user activity, events, and contact info.

## 📅 Event Management
- **Event Lifecycle**:
  - Create, edit, and delete events.
  - **Approval Workflow**: Admins can approve or reject event submissions.
- **Public & Private Events**: Control event visibility.
- **Responsive Grid**: Beautiful card layout for browsing events.
- **Detail View**: In-depth event information with participant tracking.

## 🎓 Marks & Grading
- **Student Performance**: Track and manage student marks.
- **Mobile-First Design**: Optimized cards for viewing grades on small screens.
- **Dialog Details**: Expandable detailed view for individual student records.

## 🎨 UI/UX & Theming
- **Dark Mode**: Fully supported with a seamless **Circular Reveal Animation**.
- **Responsive Design**: Adapts perfectly to Mobile, Tablet, and Desktop.
- **Modern Components**: Built with **Shadcn/ui** and **Tailwind CSS**.
- **Visual Feedback**: Loading states, toast notifications (Sonner), and interactive hover effects.

## 🔒 Security
- **Firebase Authentication**: Secure login and session management.
- **Role Guards**: Protected routes ensuring only authorized users access specific pages.
